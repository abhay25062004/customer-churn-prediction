# Customer Churn Prediction

This project analyzes customer data to understand why customers leave a service.

## Project Steps

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Data Visualization
- Feature Selection
- Machine Learning Model
- Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
